# SNAKE-GAME

# Classic Snake Game in Python

A modular, desktop Snake game developed in Python using standard GUI libraries (`tkinter`).

## Features
- **Grid-based Movement**: Precise movement controls using keyboard arrow keys.
- **Direction Lock**: Prevents accidental self-collision when pressing opposite directions rapidly.
- **Dynamic Score Tracking**: Real-time score display updating on food ingestion.
- **Game Over & Collision Detection**: Triggers on hitting screen borders or snake body segments.

## Prerequisites
- Python 3.8 or higher
- `tkinter` (bundled with standard Python installations on Windows/macOS; on Linux, install via `sudo apt-get install python3-tk`).
